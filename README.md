# PC Checcer

Dashboard web in italiano che presenta i componenti di un PC e suggerisce l'upgrade più utile, con una UI responsive e leggibile.

## Avvio

Apri `index.html` in un browser moderno. Non servono dipendenze o un server.

> Nota: una web app statica non può leggere direttamente tutti i componenti hardware per motivi di sicurezza del browser. I dati mostrati nella demo sono pronti per essere collegati a un piccolo backend o a un'app desktop (per esempio con Tauri/Electron) che esegua la scansione reale.
